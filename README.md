# Booklets 2026

Math booklets for Colegio San Patricio, taught by Miss Marcela Sársfield Arias.

Open `index.html` for the three courses: Google Classroom codes, the unit list, and the booklet. Page numbers in the index are PDF pages.

| Year | File |
| --- | --- |
| 1st year | [booklets/1st-year-2026.pdf](booklets/1st-year-2026.pdf) |
| 2nd year | [booklets/2nd-year-2026.pdf](booklets/2nd-year-2026.pdf) |
| 3rd year | [booklets/3rd-year-2026.pdf](booklets/3rd-year-2026.pdf) |

The embedded reader needs the folder to be served. From this directory:

```bash
python3 -m http.server 8765
```

Then open `http://localhost:8765`. The PDF links also work if you open the files directly.

The 2nd year file is the booklet for this course; its running header still says Math II - 2025. In the 3rd year file, the statistics pages still say Math III - 2024.
